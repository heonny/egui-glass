# Asset provenance

The published `egui_glass` library contains Rust/WGSL source, its README, and the MIT license.
The demo images and branding below are repository assets, not part of that crate archive.

## Demo images

The demo uses reproductions of paintings by Claude Monet (1840–1926). The artworks are in
the public domain. The museum and Wikimedia Commons pages below document the works and
identify their reproductions as **Public Domain**.

| File in `examples/asset` | Work | Source / rights reference |
|---|---|---|
| `Claude_Monet_-_Woman_with_a_Parasol.jpg` | Woman with a Parasol | [National Gallery of Art — Public Domain](https://www.nga.gov/artworks/61379-woman-parasol-madame-monet-and-her-son) |
| `Claude_Monet_The_Studio_Boat.jpg` | The Studio Boat | [Wikimedia Commons — Public Domain / PD-Art](https://commons.wikimedia.org/wiki/File:Claude_Monet_The_Studio_Boat.jpg) |
| ``Le_Pont_d`_Argenteuil_-_Claude_Monet.jpg`` | Le Pont d'Argenteuil | [Wikimedia Commons — Public Domain / PD-Art](https://commons.wikimedia.org/wiki/File:Le_Pont_d%60_Argenteuil_-_Claude_Monet.jpg) |

Wikimedia Commons applies [PD-Art](https://commons.wikimedia.org/wiki/Commons:When_to_use_the_PD-Art_tag)
to faithful reproductions of two-dimensional public-domain artwork. These credits are provided
for attribution and traceability; the paintings are not relicensed under the project's MIT license.

`docs/demo.png` is a screenshot of the demo using the artwork credited above.

## Branding

The icons and README logo in `assets/branding` were generated with an image-generation tool;
the prompts are recorded in [`prompts.txt`](../assets/branding/prompts.txt). They are project
branding, not official Apple, egui, or Rust logos. No third-party endorsement is implied.
